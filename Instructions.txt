Discovery & Taxonomy PhaseObjective: Audit all network egress points and define a data hierarchy.Instruction: Trace all instances of yfinance, google-finance-api, or raw requests/aiohttp calls.Deliverable: A Data Source Catalog categorized by:Static/Immutable: Historical prices, past quarterly earnings (e.g., 2025 Q1 PE), and sector info.Semi-Dynamic: Technical indicators (SMA 50/180), annual dividend yields.Highly Dynamic: Real-time price, RSI, intraday volume.2. Schema Design for ExtensibilityObjective: Transition from a flat storage model to a multi-tenant, intent-aware schema.2.1 Database ArchitectureImplement a Global-Context-Specific hierarchy.Global Table: Core ticker metadata (Company Name, Exchange, Sector).Time-Series Table: OHLCV data with a last_updated timestamp and source tag.Contextual/Metadata Table: Store attributes with an Update TTL (Time-To-Live).Example: {"attribute": "PE_Ratio", "value": 15.4, "update_logic": "Quarterly", "stale_after": "2026-07-01"}.2.2 Design PrinciplesAccess Width: Ensure the DB supports bulk lookups (e.g., fetching 50 tickers' SMA in one query).JSONB Support: Use NoSQL-style columns for "Calculated Indicators" to allow for new formula additions without schema migrations.3. The "DB-First" API ImplementationObjective: Wrap all network logic in a Data Provider Interface.3.1 The Fetch Logic FlowReplace direct network calls with a DataOrchestrator:Check DB: Query for the ticker + attribute.Evaluate Freshness: Compare last_updated against the data type’s specific TTL.Return/Enqueue:If Fresh: Return DB data immediately.If Stale/Missing: Log the "Cache Miss," return the stale data (if available and acceptable), and push the ticker to the Priority Queue.3.2 Background Worker Strategy (The Updater)The background process must be an asynchronous loop managing two queues:High Priority (On-Demand): Tickers requested by the user in real-time that were missing from the DB.Low Priority (Maintenance): Routine sweeps of stale entries (e.g., daily SMA updates).4. AI-Driven Refresh LogicObjective: Optimize bandwidth by assigning "Intelligence" to data types.Instruction to AI:Analyze Intent: For every data type, define an update_strategy.Static Data: Set is_immutable = True. Once stored, never re-fetch.Drift Analysis: For values like the 180-day SMA, set a "Lazy Refresh" (e.g., 3-day TTL). Since the denominator is large, one day's price movement has a marginal impact on the average.Volatility-Based Refresh: Dynamically shorten TTLs for high-beta stocks or during earnings weeks, and lengthen them for "Wide Moat" stable assets.5.
